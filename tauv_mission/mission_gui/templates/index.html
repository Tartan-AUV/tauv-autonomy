    Config · Positions

    These seed self.positions on the sub at launch. move_to offsets are relative to whichever one they reference, rotated into that task's own heading -- start is the fixed origin (0,0,0) for absolute positioning. CV overwrites the rest live once the sub is running, so editing values here only affects the initial guess before anything's been detected. You can keep several positions files (e.g. one per pool); the Positions dropdown in the top bar picks which one is active, and saving a mission records that choice so the planner loads the same file at launch.
